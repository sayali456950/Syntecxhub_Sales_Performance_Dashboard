# Sales Performance Dashboard using Power BI

## Project Overview
This project analyzes sales data using Microsoft Power BI to understand sales performance, profit, product categories, and regional trends.

## Tools Used
- Microsoft Power BI Desktop
- Sample Superstore Dataset

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Sales and Profit Analysis by Category
- Region-wise Sales Analysis
- Interactive visualizations

## Dataset
Sample Superstore sales dataset.
